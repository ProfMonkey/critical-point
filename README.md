# 临界点 · ProfMonkey v1.2 「超燃回响」

🐒 一个可离线游玩的手机浏览器连锁爆炸小游戏。核心操作不变：**点击格子，数字+1，达到临界值引发连锁反应**。支持首次新规则入场动画、29关、6种模式、3个Boss、任务、皮肤和本地档案。

## 试玩

下载 `临界点_v12_超燃回响版.html`，使用现代浏览器直接打开即可。也可以通过 `index.html` + 同目录 `*.js`、`theme.css` 用本地静态服务打开。

## 本次更新

- **爽快节奏**：默认启用，加快连锁爆炸之间的等待；按钮一键切换经典速度，记住玩家设置。
- **回看最后一击**：结算界面也可以完整回放刚才的一次爆炸，播放期间不改数据、不再次领取奖励。
- **离线成绩海报**：在游戏中或结算页点击「🖼 生成战绩海报」，使用原生 Canvas 绘制 720×1280 PNG，包含真实分数、最长连锁、爆炸次数、棋盘与当前外观主题。可保存或使用系统分享；不上传数据。
- **特效易用性**：支持系统「减少动态效果」偏好；提供短动画路线，低动态偏好下关闭额外粒子和移动光束。
- **保留自动教学**：首次接触特殊棋子、目标或模式时先自动演示，演示不计入真实进度。
- **兼容旧存档**：继续沿用 v0.3–v1.0 的 localStorage 数据键。

## 本地测试

```bash
node engine.test.js
python bundle.py
python browser_v11_test.py
python browser_v12_test.py
```

`browser_*` 测试需要 Python Playwright + Chromium。本项目未集成第三方 CDN 或分析代码。

## 隐私与部署

分数、徽章、外观、历史、教学标记保存在当前浏览器；海报在本机生成。清除站点数据会删除进度。可在仓库 Settings → Pages 打开 GitHub Pages 使用根目录 `index.html` 在线游玩。

## 来源和许可

玩法借鉴经典数字连锁反应思路；此仓库没有自动声明第三方资产许可，未来引用素材时应单独核验并遵循许可。
