# 临界点 v2.5 · 轻松进阶与互动教学

基于 v2.4 公测版，修复后期部分关卡难度过高、规则演示太快和反复播放的问题。保留 29 关、五岛地图、6 种模式、3 场 Boss 战、技能与收藏、成绩卡和离线统计。

## v2.5 变化

- 重新调校 13 关的目标、步数或棋盘种子，重点关注 20—29 关。
- 新机制首次出现时，只自动演示一项规则；教程的每一步由玩家决定何时前进。
- 支持点击高亮练习格、上一步、从头再看、跳过以及从关卡任务卡随时重播。
- 通关领奖至少进行 3 次实际操作，避免一两下结束；已有目标不会被删除。
- 失败时可免费续关 +3 步一次，保留当前棋盘。
- 数字临界值 6 放在超载模式，不在连续两关强制教授两种新临界值。
