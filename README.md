# 临界点 · ProfMonkey v1.1

手机友好的离线浏览器连锁爆炸游戏。**点击格子数字+1，达到当前临界值即爆炸，并向相邻格传能量。**

## 快速开始

下载 `临界点_v11_战术预览版.html` 后用 Chrome、Edge 或手机浏览器打开，无需联网。或者运行 `index.html` （需通过本地静态服务以获得一致体验）。

## v1.1 改动

- **战术预览（默认关闭）**：点击“🔮 战术预览”，选择落点可提前查看预计得分、连锁层数、爆炸数量、目标格和 Boss 伤害，按“确认引爆”才真正执行。关闭时维持单击立即爆炸的原本操作。
- **高光回放**：回放上一点击的连锁过程。不会扣除步数、改变分数或重复领取奖励；只有上一步有实际爆炸才可使用。
- **预测可视化**：紫色轮廓标注实际爆炸格，蓝色虚线标注可能受到传能量影响的格。
- **单文件离线包**：保留独立源码、自动新规则演示、29关、6模式、Boss、每日任务、晶核和个人战绩。
- **兼容旧存档**：沿用关卡星级、装备和任务数据的旧 localStorage 键，未主动迁移或清空。

## 规则质量保证

`node engine.test.js` 进行规则与关卡基本回归；`python browser_v11_test.py` 运行 Playwright 浏览器交互测试。新玩法没有修改规则引擎。所有新规则首次出现时仍会通过旧教程流程自动演示。

## 隐私与部署

数据默认仅保存本机浏览器 localStorage；没有在线账户、微信登录或在线排行榜。清除浏览器站点数据会丢失进度。

推荐部署 GitHub Pages：仓库设置 Pages -> Deploy from a branch -> main / (root)，即可用 GitHub Pages 提供在线试玩。
